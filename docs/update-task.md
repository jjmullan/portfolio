# update-task

## 목적

- `docs/update-task.md` 변경 이력 관리
- 기록 대상은 **서비스 직접 변경만**:
  - 실제 코드 변경
  - 의존성 패키지 설치/변경
  - 정적 파일 추가/변경/삭제
  - 기타 변경 사항

## 실행

1. 현재 브랜치/최근 커밋 확인
2. 최근 이력 vs 현재 변경 파일 비교
3. 변경사항 3단계 정리 (`대분류 -> 중분류 -> 소분류`)
4. DB에서 `날짜 end == 오늘` 페이지 조회
5. 있으면 업데이트, 없으면 생성
6. `작업 내역`은 짧은 문장만 작성(접두어 금지)
7. 날짜는 `작업 시작 일자 ~ 오늘`
8. 본문 하단에 정리 내용 추가

## DB

- 대상: `https://www.notion.so/choiyoungjune/30d21bc2456c80f0b16ee9cd4e142a88`
- 사전 확인: `codex mcp list`

## 작성 규칙

- `작업 내역` 예시: `라우팅 에러 페이지 추가 및 패키지 정리`
- 금지: `변경 내용 요약:` 같은 접두어
- 같은 종료 일자 페이지가 있으면:
  - 새 페이지 생성 금지
  - `작업 내역` 제목 최신화
  - 하단에 이번 업데이트만 이어쓰기

## 본문 형식(고정)

- `##` 대분류 내용
- `###` 중분류 내용
- 일반 텍스트: 소분류 내용
- 금지: `대분류:`, `중분류:`, `소분류:` 라벨

## 실행 절차(동의)

1. 먼저 계획/예상 반영만 제시
2. 사용자 동의 후 Notion 쓰기 실행
